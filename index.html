// What's inside

Two sides. One platform.

LedgerFlow MVP ships with a cashier-facing POS terminal and a banker-facing reporting dashboard — everything you need to start recording and reconciling from day one.

POS Terminal
🧾

Fast Transaction Recording

Cashiers log sales in seconds: item, amount, payment method (cash/card/transfer). Every sale is time-stamped and stored locally with sync to the central ledger.

POS Terminal
🗂

Receipt & Session History

Drill into any transaction. Print or email receipts. Close daily sessions with a single tap — automatically locking that day's records for audit integrity.

Banker Side
📊

Live Financial Dashboard

Bankers see total balance, daily/weekly revenue trends, average ticket size, and pending settlements — updated as each transaction lands.

Banker Side
📤

Settlement & Reporting

Run end-of-day reconciliation reports, flag discrepancies, and export clean CSV or PDF summaries for accounting — no spreadsheet gymnastics needed.

Platform
🔐

Role-Based Access Control

Cashier accounts see only the POS. Banker accounts unlock the full dashboard. Admin creates users and assigns roles — keeping sensitive financial data behind the right doors.

Where to find it

Once installed, LedgerFlow runs as a local web server. Access the POS terminal and the banker dashboard from any device on the same network using the addresses below. No internet connection required during operation.

For production deployment, point your domain's DNS to your server IP and configure the included nginx.conf. Full instructions are in the setup guide PDF.

Default Local Addresses
POS Terminal    http://localhost:3000/pos
Banker Dashboardhttp://localhost:3000/banker
Admin Panel     http://localhost:3000/admin
API Docs        http://localhost:3000/api
